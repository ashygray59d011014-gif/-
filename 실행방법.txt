가장 쉬운 방법:
1. 실행하기.bat 파일을 더블클릭합니다.
2. 처음 실행할 때 필요한 파일이 자동으로 설치될 때까지 기다립니다.
3. 서버 준비가 끝나면 브라우저가 자동으로 열립니다.
4. 게임을 하는 동안 "파란 길드 서버"라는 검은 창은 닫지 마세요.

브라우저에 ERR_CONNECTION_REFUSED가 표시되면:
- 서버 검은 창이 열려 있는지 확인하고 3~5초 후 새로고침하세요.
- 서버 창을 이미 닫았다면 실행하기.bat를 다시 더블클릭하세요.

직접 실행하는 방법:
1. 이 폴더에서 터미널(명령 프롬프트)을 엽니다.
2. npm install 을 입력합니다.
3. npm run dev 를 입력합니다.
4. http://127.0.0.1:5173 주소를 브라우저에서 엽니다.

캐릭터 이미지는 public/images 폴더에 넣어주세요.
이미지가 없어도 기본 초상화로 게임은 정상 실행됩니다.
